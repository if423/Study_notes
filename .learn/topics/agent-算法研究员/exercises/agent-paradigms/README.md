---

## 📋 背景

你已经学习了 AI Agent 的五大经典范式：

| 范式 | 核心规则 | 关键特征 |
|---|---|---|
| **反应式** | IF 条件 THEN 动作 | 无记忆、不推理、只活在当下 |
| **模型式** | 内部状态模型 + 感知 | 能补全未观测到的信息 |
| **目标驱动** | 搜索从当前到目标的路径 | 会"向前看"规划 |
| **效用驱动** | 多维效用函数选最优 | 能处理目标冲突和不确定性 |
| **BDI** | Belief → Desire → Intention | 有信念、愿望和承诺 |

你的任务是在一个统一的迷你框架中完成这五种 Agent 的实现。

---

## 🎯 练习目标

实现一个**网格世界清洁 Agent**：Agent 在一个 3×3 网格中移动，需要清扫脏格子。环境部分可观测——Agent 只能看到相邻格子。

```
网格示意（Agent 视角）:
┌───┬───┬───┐
│ 🧹 │ ░ │   │   🧹 = Agent 当前位置
├───┼───┼───┤   ░ = 感知到的脏格子
│   │   │ ? │   ?  = 未观测区域（模型式 Agent 要推断）
└───┴───┴───┘
```

---

## ✅ 需要完成的任务

打开 `starter.py`，找到所有 `# TODO` 标记（共 5 个），逐一实现：

1. **`ReactiveCleaner`** — 纯反应式：感知到相邻有脏格子就移动过去清扫
2. **`ModelBasedCleaner`** — 模型式：维护内部地图，对未观测格子做默认假设
3. **`GoalBasedCleaner`** — 目标驱动：BFS 搜索最短清扫路径
4. **`UtilityBasedCleaner`** — 效用驱动：用多维效用函数选择最优行动（距离 + 确定性 + 能耗）
5. **`BDICleaner`** — BDI：Belief（地图认知）→ Desire（所有脏格子清零）→ Intention（承诺清扫某个脏格子）

每个 Agent 类中只需实现 `decide()` 方法（以及该范式特有的辅助方法）。
